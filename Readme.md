# 📊 Ecommerce Customer Intelligence Dashboard

> An end-to-end Data Analytics project that transforms raw ecommerce data into actionable business insights using SQL Server and Microsoft Power BI.

---

# 🚀 Project Overview

Modern ecommerce businesses generate millions of records across customers, orders, products, sellers, reviews, and payments.

While the data contains valuable information, making business decisions directly from raw transactional data is difficult.

This project demonstrates the complete analytics lifecycle by converting raw ecommerce data into an interactive Business Intelligence solution capable of answering critical business questions.

The project covers:

✔ Data Cleaning

✔ SQL Data Warehousing

✔ Business Analysis

✔ DAX Calculations

✔ Interactive Dashboards

✔ Business Storytelling

---

# 🎯 Business Problem

An ecommerce company wants to understand:

- Which product categories generate the highest revenue?
- Which customers contribute the most revenue?
- Which sellers perform the best?
- Which states generate maximum sales?
- How are sales changing over time?
- What is the average customer review score?
- Which regions require business attention?

Instead of manually analyzing thousands of records, management requires an interactive dashboard for faster decision-making.
